往生咒・梵文發音練習

｜逐句對照・標準音・錄音比對（個人原型）

ā ī ū e o 長音（拉長約兩倍） th bh dh kh 送氣音（多吐一口氣） ṭ ḍ ṇ ṣ 捲舌音 ṛ 捲舌母音 ṃ 鼻音 ˺（如 ㄅㄨㆵ˺ ㄉㄏㄚ～）表示嘴巴或舌頭在這個位置閉住、停一下，不放開也不換氣；濁音（ㄅ、ㄉ）閉住時喉嚨仍然振動；前面的母音不要拉長。ㆴ ㆵ ㆶ 是閉住的位置（雙唇／舌尖／舌根），其他位置用小字注音（如捲舌 ㄉ）。 右上小字（如 ㄧㄚㄍ ㄙㄚㄇ）：輕輕放開、帶過，馬上接後面的 ㄙ／ㄕ，不用停。 句尾的 phaṭ 泮（ㄆㄚㄉ˺）：照古代規範是閉住不放；現代唸誦常輕輕放開，兩種都可以。

注音只是近似讀音：「～」表示長音；ㄍ／ㄉ／ㄅ 在梵文 g／d／b 時要唸成濁音（聲帶振動）；ㄅㄏ、ㄉㄏ 表示濁送氣音 bh、dh。

🎙 錄音比對怎麼用：按「錄音比對」後唸該句，唸完會自動停止。系統用 Chrome／Edge 內建的印地語（hi-IN）語音辨識把你的聲音轉成天城體，再和標準文字逐音節比對。
⚠️ 這只是近似檢查：印地語辨識不是為梵文設計的，長短音、送氣有時會被自動「修正」或誤判，結果僅供參考，請同時用「我的錄音」和標準音對照著聽。辨識需要連網，第一次使用時瀏覽器會要求麥克風權限。
辨識設定說明

1. Android 用 Chrome、iPhone 用 Safari 開啟

從 LINE、Facebook 等 App 直接點開的網頁（App 內建瀏覽器）通常不能語音辨識。請點選單選「用其他應用程式開啟／在瀏覽器開啟」，或複製網址貼到 Chrome（Android）或 Safari（iPhone）。LINE 裡也可以直接點：在外部瀏覽器開啟。

2. Android：加入印地語語音辨識

  1. 打開手機「設定 → 系統 → 語言 → 語音輸入」（各品牌名稱不太一樣），或打開 Google App → 右上角頭像 → 設定 → 語音 → 語言。
  2. 加入「हिन्दी（भारत）／印地文（印度）」，主要語言維持中文就可以。
  3. 在「離線語音辨識」下載印地文語音包。
  4. 把 Chrome 完全關掉（從最近使用的 App 滑掉）再重新打開這個網頁。

Android 版 Chrome 不能同時錄音和辨識，所以在 Android 上「錄音比對」只做辨識；想聽自己的聲音，辨識完再按「🎙 錄下來對照」。

3. iPhone／iPad（Safari）

  1. 用 Safari 開啟（iOS 14.5 以上）。iPhone 上的 Chrome、LINE 等 App 裡的瀏覽器，語音辨識常常不能用。
  2. 打開聽寫：「設定 → 一般 → 鍵盤 → 啟用聽寫」。還是不行的話，也打開 Siri（「設定 → Siri」，有些機型叫「Apple Intelligence 與 Siri」）。
  3. 加入印地語：「設定 → 一般 → 鍵盤 → 鍵盤 → 新增鍵盤 → 印地文」，聽寫語言就會有印地語。印地語辨識要連網。
  4. 第一次按「錄音比對」時，Safari 會問能不能用麥克風和語音辨識，兩個都選「允許」。之前按過不允許的話，到「設定 → 隱私權與安全性 → 語音辨識」把 Safari 打開。

iPhone 也不能同時錄音和辨識，所以「錄音比對」只做辨識；想聽自己的聲音，請按「🎙 錄下來對照」。剛播完標準音就按錄音，辨識偶爾會沒反應（Safari 的已知問題），等一兩秒再按「再辨識一次」就好。

4. 麥克風權限

  • 第一次按「錄音比對」時，瀏覽器會問能不能使用麥克風，請選「允許」。
  • Android Chrome：點網址列左邊的圖示 → 權限 → 麥克風 → 允許；還是不行的話，到手機「設定 → 應用程式 → Chrome → 權限 → 麥克風」打開。
  • iPhone Safari：點網址列旁的頁面選單（aA）→ 網站設定 → 麥克風 → 允許；或到「設定 → App → Safari → 麥克風」（iOS 17 以前是「設定 → Safari」）。
  • 電腦版 Chrome／Edge：點網址列左邊的圖示 → 麥克風 → 允許。
